# Padel Athlete Coach — V5 / cycle de test 8 semaines

Cette version est destinée à être utilisée pendant 8 semaines avant réévaluation.

Nouveautés :
- tableau de bord charge/récupération/douleur/disponibilité ;
- détection simple de hausse rapide de charge et de signaux douloureux ;
- périodisation sur 8 semaines ;
- affûtage lorsqu'un tournoi est inscrit au calendrier ;
- semaine d'allègement ;
- protocole standardisé de re-test à 8 semaines ;
- suggestions de substitution d'exercices selon les douleurs ;
- moteur adaptatif prescrit → réalisé → prochaine cible ;
- parcours calisthénie progressifs avec critères de maîtrise.

Après 8 semaines : Réglages > Données > Exporter, puis transmettre le JSON pour révision.

Les scores de charge, récupération et disponibilité sont des indicateurs internes de suivi personnel, non des scores médicaux validés.
